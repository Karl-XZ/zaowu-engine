# 造物引擎 ZAOWU ENGINE — UI 设计方案 V1.1

> 对应 PRD V1.4（效果图 + 对话调整 ≤10 次 → 图生 3D）· 2026-11-12
> 设计稿：同目录 `png/`（6 张 2 倍高清图）与 `html/`（6 个可在本地浏览器直接打开的页面，页面间可点击跳转）

---

## 1. 设计目标

| 目标 | 设计手段 |
|---|---|
| 进站 3 秒内被震住 | 首屏超大字 + 构成主义几何构图 + 旋转的 3D 线框礼盒，整屏只有一句话：「心意，要有形状。」 |
| 3 秒内看懂能做什么 | 两块同等分量的引擎按钮（创意 3D / 精确 CAD），每块写清适用品类 |
| 消除付费顾虑 | 价格规则在首屏底部、价格区和每个生成按钮旁都重复出现：「每天 3 个免费 ／ 之后 ¥5 ／ 不合格不收钱」 |
| 建立「真能打印」的信任 | 用工程语言做视觉：毫米标注、尺寸线、检测项、`VERIFIED` 印章、SHA-256，区别于“AI 出图”类产品 |

**品牌「造物引擎」**：Logo 为红方块（礼物）+ 纸色圆（心意）+ 斜黑梁（构造），英文副标 ZAOWU ENGINE。

## 2. 视觉语言：构成主义 × 工程图纸

### 2.1 核心理念

20 世纪 20 年代构成主义海报的语法——**红黑二色、对角线张力、几何基本形、粗壮无衬线大字、文字即构图**——与工程制图的语法——**网格纸、尺寸线、等宽数字、检测印章**——叠加。前者负责震撼和记忆点，后者负责“这是能造出来的东西”的可信感。

### 2.2 色彩

| Token | 色值 | 用途 |
|---|---|---|
| `--paper` | `#F1EBDD` | 全站底色（纸张感暖白，不用纯白/纯黑大底） |
| `--ink` | `#141210` | 文字、粗框线、黑色体块、反白区块 |
| `--red` | `#D52B1E` | 唯一强调色：主按钮、关键数字、警示、圆形主体 |
| `--paper-2` | `#FBF8F1` | 输入框底 |
| `--rule` | `#C9BFAE` / `#D9D1C0` | 细分隔线、黑底上的次级文字 |
| `--muted` | `#5A5249` | 辅助说明文字（在 paper 上对比度 ≥ 4.5:1） |

**规则**：一屏最多红、黑、纸三色；红色只给“最重要的一件事”。纸色与红色互为前景时对比度约 4.9:1，满足 AA。热力图等数据色只用红-纸-黑的明度梯度，不引入新色相。

### 2.3 字体

| 角色 | 字体 | 用法 |
|---|---|---|
| 中文标题 / 正文 | Noto Sans SC 900 / 700 / 500 | 标题一律 900，字距收紧（-1 ~ -2px），行高 0.92–1.0 |
| 拉丁 / 大数字 | Unbounded 900 / 700 | `3`、`¥5`、`01–04`、`ENGINE A` 等标签；大数字可用 2px 描边空心 |
| 技术数据 | JetBrains Mono 700 | 一切毫米值、文件格式、规则版本、哈希、额度计数 |

**字号阶梯**（流式 clamp）：英雄标题 76→196px；区块标题 44→96px；卡片标题 22–28px；正文 15–20px；标签 11–13px。

### 2.4 构图语法（5 条）

1. **对角线**：每个主要区块至少一条倾斜黑色梁（-28° / -24° / -18° / 8°），打破网格的平静。
2. **圆 + 方**：红色大圆是“主体/成果”的象征，黑色方块是“结构/工程”的象征，两者同屏形成张力。
3. **3px 粗框**：所有容器、按钮、表格用 3px 墨色描边，直角，无圆角（唯一例外：CAD 工程图里的真实圆角）。
4. **硬阴影**：可点击的主要元素使用 `6–14px` 实色偏移阴影（无模糊），悬停时元素向左上移动 4px、阴影加深——像印章压下。
5. **网格纸**：工作区、工程图、预览视口铺 14px / 40px 浅墨网格，暗示“这是在制图”。

### 2.5 图形元素库

| 元素 | 含义 | 出现位置 |
|---|---|---|
| Logo：红方块 + 纸色圆 + 斜黑梁 | 礼物（方）+ 心意（圆）+ 构造（梁） | 导航 |
| 3D 线框礼盒（CSS 3D 旋转） | 正在成形的模型 | 首页英雄区、工作台待生成态 |
| 尺寸线 + 等宽数字 | 精确、可制造 | 英雄区注释、CAD 工程图 |
| 斜盖印章（`不合格 · 不收钱` / `VERIFIED 合格交付`） | 承诺、验收 | 价格区、模型页 |
| 跑马灯黑带（-2.5°） | 流程一句话 | 首页英雄区下方 |
| 空心大编号 `01–04` | 步骤 | 流程区、工作台分步 |

## 3. 页面方案

### 01 首页 `/`（`01-首页.png`）

自上而下 8 段，每段都是一张“海报”：

1. **导航**：Logo / 创意 3D / 精确 CAD / 价格 / 流程 / 我的作品；右侧常驻 `今日免费 3/3` + 黑色登录按钮。
2. **英雄区**：左侧标题「心意，/ 要有形状。」（“要有形状”为红色）+ 一句说明 + 两块引擎按钮（红 / 黑，等宽等高，标 `ENGINE A · AHOLO`、`ENGINE B · CAD` 和品类）+ 价格一句话。右侧构图：红色大圆 + 虚线轨道慢转 + 斜黑梁 + 旋转线框礼盒 + 三个技术注释（`60.0 mm`、`壁厚 ≥ 2.0 mm ✓`、`WATERTIGHT · MANIFOLD ✓`）+ 空心 `3D`。左边缘竖排 `TEXT → MODEL → PRINT → GIFT`。
3. **跑马灯**：说出心意 ■ 生成模型 ■ 制造预检 ■ 锁定生产文件 ■ 嘉立创打印 ■ 送到 TA 手里。
4. **四步流程**：01 说一句话 / 02 聊着改（最多 10 次）/ 03 转 3D · 预检 / 04 打印送达；第 03 格整格红底，是全页的视觉重心，并挂 `VERIFIED_DELIVERABLE` 标签。
5. **双引擎对比**：左红右纸，用斜切边（clip-path）拼合；各放一句 PRD 中的真实示例需求；CAD 侧画一个带尺寸线的钥匙扣小图。
6. **价格**：巨大红色 `3` 与黑底 `¥5` 并列，中间斜盖「不合格 · 不收钱」印章；下方四格补充：永久免费 / 修复不扣次 / CAD 改尺寸免费 / 制造费直付工厂。
7. **从屏幕到桌面**：黑底四步链路（生成+预检 → 锁定文件 → 嘉立创报价打印 → 配送），明确“以嘉立创实际报价为准”。
8. **收尾 CTA**：「现在，说出你的礼物。」+ 带硬阴影的输入条 + `免费生成 →`。页脚说明 Aholo / 嘉立创的责任边界。

### 02 对话设计 `/create`（V1.1 重做）

对应主流程“一句话 → AI 效果图 → 对话调整（≤10 次）→ 确认转 3D”。

- **会话条（黑底）**：本次锁定的材料 / 尺寸 / 用途；右侧 **10 格次数条**（已用为红色实心，剩余为空心），并以 Unbounded 大字显示 `7/10`，次数一眼可见。
- **左栏 · 对话**：用户消息为黑底气泡，并用红色小标标注调整维度和第几次（如 `造型 · 第 1 次`）；AI 回复带版本号 `v0…v3`。
  - **预检拦截卡（红底）**：例如“飘浮的星星打印不出来 → 建议改成双手抱着”，明确写出“本次未消耗调整次数”，提供「就这么改 / 换个说法」两个选项。
  - **单色材料提示**：调整颜色时提示“打印件为材料本色”。
  - **底部输入区**：造型 / 风格 / 颜色快捷标签、输入框，发送按钮上写明“第 4/10 次”。
- **右栏 · 效果图舞台**：中性影棚底色加软阴影，突出效果图本身（设计稿中为示意图）；左上为超大版本号 `v3` 和本版摘要；右上为“单主体 ✓ 一体底座 ✓ 无悬空 ✓ / 适合转 3D”的转换前质检标签。
- **版本条**：v0～v3 缩略图，当前版本加红框；v4～v10 显示为虚线空槽，让“最多 10 次”的上限可视化。点任一版本可以回看或直接确认。
- **主按钮**：「确认 v3，转成 3D →」，副文案“修复 · 预检 · 切片 / 合格才扣已预留的 1 次”；旁边列出硬性要素和 24 小时申诉说明。

### 03 精确 CAD `/cad`

- 左：自然语言输入 → 自动抽取参数；徽标「命中本地模板 · 外部 API 调用 0」；六格参数表（长 / 宽 / 厚 / 孔径 / 孔中心距 / 圆角，单位 mm）；三条实时规则校验（壁厚、孔边距、文字笔画）；两个按钮：「重建模型（纯参数 · 不计次 · 今日 3/30）」与「确认并交付」。
- 右：**工程图即主视觉**——按 1:1.4 比例绘制 80×30×4 铭牌俯视图与侧视图，含尺寸线、中心线、红色孔位与 `2×⌀5.0` 标注；底栏显示 CAD 内核实测外形、实体数与 STEP / STL / GLB 导出。

### 04 模型预览与制造预检 `/models/:id`

- 顶部六段任务进度：效果图确认（v3 · 调整 4/10）→ 图生 3D → 修复 → 制造预检 → 切片 → 合格交付（红底）。3D 预览与确认的效果图一致（抱星星）。
- 左视口：几何化的“月亮上的小熊”占位模型（实际为 Three.js / model-viewer），斜盖 `VERIFIED 合格交付` 印章；底部工具条：旋转 / 缩放 / 重置视角 / **壁厚热力图** / 线框；右下热力图图例（< 2.0 阻断）。
- 右栏：黑色标题「制造预检报告」+ 规则版本；逐项结果（水密流形、外形尺寸、P5 壁厚、连通实体、切片支撑量与预计耗时、对照效果图 v3、自动修复 1 处·免费）；下载区（STL / 3MF / GLB / 检测报告，标“同一版本永久免费”，显示已锁定 SHA-256）；主按钮「导出并前往嘉立创下单 →」（PRD 模式 B，API 未开通前不写“一键下单”）；额度核销提示、24h 申诉入口、版本切换。

### 05 付费生成 `/pay`

- 左侧在红色大圆上放巨型 `¥5`，副标题「生成下一个合格模型」，并给出替代选择：明天 00:00 恢复 3 次免费。
- 右侧订单卡（硬阴影 14px）：内容 / 材料尺寸 / 应付；三步承诺（付款先冻结 → 通过预检才扣款 → 失败自动恢复可退款）；「支付宝付款 ¥5.00」主按钮；审美与申诉规则小字。金额由服务端下发，前端只展示。

### 06 移动端首页（390×844）

英雄标题分三行 72px；红圆 + 斜梁 + 礼盒移到右侧中部；两块引擎按钮堆叠在拇指区；底部黑色栏固定展示 `3 每天免费 / ¥5 之后每个 / 不合格 不收钱`。

## 4. 动效

| 动效 | 参数 | 目的 |
|---|---|---|
| 线框礼盒自转 | 16s 线性循环，rotateX -22° | 首屏“活”起来，暗示 3D |
| 虚线轨道慢转 | 40s 线性 | 增加纵深，不抢注意力 |
| 英雄文字上浮入场 | 0.9s，cubic-bezier(.2,.8,.2,1) | 首屏节奏 |
| 跑马灯 | 38s 线性 | 一句话讲完流程 |
| 按钮按压 | 0.18s，位移 -4px + 硬阴影 8px | 构成主义的“印章”触感 |
| 模型页占位摇摆 | 7s ±18° | 预览可交互的暗示 |
| 生成中（开发实现） | 线框礼盒面逐片“填实”，进度条分段点亮 | 让等待有意义 |

所有动效在 `prefers-reduced-motion: reduce` 下关闭。

**开发阶段可升级**：首屏礼盒换成 Three.js 实时渲染的真实示例模型（GLB），鼠标视差 ±6°；滚动驱动对角线梁的入场位移。

## 5. 组件规范

| 组件 | 规范 |
|---|---|
| 主按钮 | 红底纸字、3px 墨框、最小高 52px（关键 CTA 64–72px）、硬阴影 6–8px |
| 次按钮 | 墨底纸字或纸底墨框，同尺寸 |
| 额度徽标 | 等宽字、2px 墨框，剩余数字红色；为 0 时整块反白为墨底 |
| 输入框 | 3px 墨框、`#FBF8F1` 底；数值输入用等宽 20–24px，单位用分隔格显示 `mm` |
| 材料卡 | 选中 = 墨底反白；未验证 = 虚线灰框 + 「验证中」，不可选 |
| 预检卡 | 红底纸字，左侧 Unbounded 「!」，附「采纳建议 / 我自己改」 |
| 清单 / 报告行 | 左项目右结果，结果用等宽粗体；行间 1–2px 分隔 |
| 印章 | 4–5px 红框、旋转 -12°、纸底外扩 8px 留白 |
| 进度条 | 五段等分格，完成段带 ✓ 与耗时，最终段红底 |

**无障碍**：所有可点击元素 ≥ 44px；真实 `<button>` / `<a>` / `<label>`；装饰几何 `aria-hidden`；工程图与模型视口带 `role="img"` 和完整中文描述；颜色区分同时有明度差。

## 6. 响应式

- 断点 820px：对角拼接改为上下堆叠，竖排装饰文字隐藏。
- 首页、工作台、CAD、模型页均为流式布局（flex-wrap + clamp 字号），最大内容宽 1440px，手机侧边距 16px，无横向滚动；CAD 工程图在窄屏放入可横向滚动的框内。
- 移动端主操作放在下半屏拇指区。

## 7. 交付与开发建议

- **技术栈**：Next.js + Tailwind（将上述 Token 写入 `tailwind.config`），3D 用 model-viewer（P0）→ Three.js（热力图、线框切换）。
- **字体加载**：Noto Sans SC 体积大，正式环境按页面实际用字子集化或使用国内字体 CDN；Unbounded / JetBrains Mono 只加载用到的字重。
- **文案即设计**：价格规则、失败不扣次、申诉窗口三句话必须与 PRD V1.3 保持一致，改规则时同步改文案。
- **待补设计**：10 次用完态（只能选版本确认或新开会话）、放弃会话确认、任务失败 / 退还权益态、额度为 0 的对话设计页、我的作品列表、管理员后台、嘉立创报价确认页（P1）、申诉弹窗。
